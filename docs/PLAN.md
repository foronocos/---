## 2. Схема данных

### Комната

```js
{
  id: 'hall', chapter: 1, title: 'Коридор', art: 'hall',
  width: 2100, floorY: 590, spawn: 140,
  doors: [{ x, to, spawnX, label, require?, lockedDialogue? }],
  props: [{
    id, x, y, w, h, label,
    type: 'note'|'loot'|'npc'|'look'|'shop'|'boss'|'rest'|'choice',
    dialogue?, item?, seeds?, once?, require?
  }]
}
```

Все координаты — мировые, камера следует за Чики. Интерактив доступен по `E` рядом с предметом или кликом.

### Диалог

```js
dialogueId = {
  start: 'a',
  nodes: {
    a: { speaker: 'Мурзила', text: '…', next: 'b' },
    b: { text: '…', choices: [
      { label: '…', next: 'c', effects: { kindness: 1, flag: 'sparedCat' } },
      { label: '…', next: 'd', require: { item: 'key' } }
    ]},
    c: { text: '…', end: true, effects: { startCombat: 'cat' } }
  }
}
```

Эффекты: `kindness`, `greed`, `flag`, `spared`, `seeds`, `item`, `maxHp`, `startCombat`, `openShop`, `ending`, `unlock`, `heal`, `note`. Проигрыватель диалогов вызывает их через `Game`.

### Состояние

```js
{
  version: 1, chapter: 1, roomId: 'living', x: 520,
  player: {
    classId, hp, maxHp, seeds,
    items: { heal, honey, double }, keyItems: { key, feather },
    hasEye, ultOwned, ultUsed,
    upgrades: { vitality, skill2, special },
    allies: { cat, pigeon, vacuum },
    flags: { sparedCat, sparedVacuum, sparedPasta, atePasta },
    kindness, greed, notesRead: [], bestiarySeen: []
  },
  taken: [], used: [], visited: [], shopChapter: 1
}
```

Сохранение пишется в `localStorage['chiki_eclipse_save_v1']` при входе в комнату, после боя, покупки и диалога. Главное меню показывает главу, класс, HP и семена сохранения.

## 3. Формулы боя

- Урон игрока: `(d6 + бонус класса) × крит × предмет × умение`.
- Крит: выпало 6 → ×2 (у Семечкового Магистра с улучшением — ×3).
- «Клюв в спину»: ×2 после крита. «Двойное зерно»: ×2 на первый удар боя.
- Урон врага фиксированный по сюжету: Мурзила 3, Пылесос 4, Макароны 5.
  Модификаторы: «Щит крыла» → 1, «Стальное крыло» → −2, «Отражение» → 1 обратно.
- HP: Рыцарь 12 / Магистр 9 / Тень 10; каждое улучшение «+3 HP» повышает максимум и текущее HP.
- Семена: 3 за босса, +1 за мирное решение, +1..2 в тайниках, 1 за выборы.
- Ульта за 6 семян: откат последнего хода (снимок HP, HP врага, счётчиков и состояния ГСЧ).
- Кубик врага показан как намерение: тип хода и ожидаемый урон; «Глаз Голубя» открывает точные числа заранее.

### Поведение боссов

- **Мурзила (15 HP).** Каждый третий ход прячется под диван — его удар не проходит. При HP ≤ 4 доступно «Предложить перемирие»: +1 семя, союзник, подсказки коротких путей.
- **Пылесос-Пожиратель (20 HP).** Слабый бросок (1–2) затягивает Чики: следующий ход пропускается. В мешке — запасной ключ и Золотое Перо. Мирный путь: уговорить (нужен Мурзила-союзник) или поделиться семенем; агрессивный — разрезать мешок (+2 семени, но жадность).
- **Хозяин Макарон (28 HP).** Раз за бой предлагает макароны: +5 HP, но два пропущенных хода. При HP ≤ 8 доступно «Разделить макароны» — мирный финал боя.

## 4. Прогрессия и концовки

- Главы: коридор → кладовка → кухня → балкон. Двери открываются после разрешения боссов; тупиков нет, ключ выдаётся при любом исходе.
- Магазины: Таракан-Торговец (под ванной) и Гоша-Голубь (подоконник кухни, после 2-й главы). Ассортимент пересобирается между главами.
- Концовки считаются по накопленным очкам: `доброта − жадность + союзники`, а не по последнему клику:
  - «Квартира-Стая» — выйти, много доброты и ≥2 союзника;
  - «Настоящее Утро» — выйти с добрым сердцем;
  - «Солнце в Клетке» — выйти, но страху нечего противопоставить;
  - «Тихий Дом» — остаться в мире с собой;
  - «Перо Затмения» — забрать перо при высокой жадности;
  - «Хранитель Квартиры» — забрать перо без жадности.

## 5. Акт II: дом выше квартиры

Балкон больше не финал: Перо рассыпается осколком, и начинается второй акт —
шесть глав, в которых Чики поднимается по дому.

### Карта комнат

| Глава | Комнаты | Босс | Условие мирного исхода |
| --- | --- | --- | --- |
| V | `stairs` → `landing` | Ключница (18 HP, 3 урона) | HP ≤ 5 |
| VI | `basement` → `boiler` | Котёл-Ворчун (22 HP, 3) | HP ≤ 6 |
| VII | `attic` → `trunks` | Моль-Хранительница (25 HP, 4) | HP ≤ 7 |
| VIII | `roof` → `antennas` | Ворон-Собиратель (30 HP, 4) | HP ≤ 8 |
| IX | `eclipse` → `mirrorRoof` | Тень Чики (28 HP, 4) | HP ≤ 8 |
| X | `nest` → `skyDawn` | Шуня (38 HP, 5) | HP ≤ 10, доброта ≥ 3 |

Двери между комнатами открываются по факту разрешения босса (`bossResolved`),
закрытые показывают диалог-подсказку: `landing_locked`, `attic_locked`,
`roof_locked`, `eclipse_locked`, `mirror_locked`, `dawn_locked`.

### Новые механики боя

- `enemyArmor` — броня Ключницы: поглощает урон до 0 и обнуляет «промах» в замки.
- `rollPenalty` — у Шуни после 60 % HP каждый бросок уменьшается на 1 (но не ниже 1).
- `shunyaPhase` / `enraged` — фазы финального боя; ярость добавляет +2 к урону.
- `steal` — Моль съедает случайный расходник, `stealSeed` — Ворон крадёт семя.
- `stolenItems` / `stolenSeeds` — счётчики для текста и статистики.
- Тень Чики отвечает 2 урона на каждый крит; «Обратный коготь» может добить её
  в её же ход, поэтому сцена боя проверяет смерть врага после хода врага.
- Союзники влияют на бой: Гоша бьёт первым, Котёл греет (+3 HP в начале боя),
  Тень добавляет +1 к урону, когда у Чики меньше половины HP.

### Данные комнат

Форма та же, что в первом акте, плюс необязательный слой декора:

```js
decor: {
  ambient: 'dust' | 'drip' | 'steam' | 'moth' | 'wind' | 'star' | 'feather',
  back: [{ art, x, y, w, h, alpha? }],
  front: [{ art, x, y, w, h, parallax?, alpha? }],
}
```

`back` рисуется вместе с фоном, `front` — поверх сцены с параллаксом.
Передний план не может закрыть Чики: если предмет попадает в полосу ходьбы,
он обрезается по линии пола.

### Графика

- `src/render/textures.js` — процедурные тайлы: обои, кирпич, кафель, доски,
  металл, ткань; кэшируются в `CanvasPattern`.
- `src/render/roomKit.js` — перспективный пол, стены с карнизом и плинтусом,
  трубы с конденсатом, конусы света, город, облака, звёзды, диск затмения.
- `src/render/decor.js` — реестр `ART` (около 70 предметов) и слои параллакса.
- `src/render/postfx.js` — цветовая коррекция по главе, виньетка, зерно,
  «дыхание» камеры.
- `src/render/spritesB.js` — шесть новых боссов; Шуня собрана слоями:
  хвост, крылья с рядами маховых перьев, тело, пух, голова с полумесяцами глаз,
  золотое перо на шнурке и контровой свет.
