# Чики: Перо Затмения

Автономная 2D сюжетная игра на чистом HTML5 Canvas и JavaScript. Никаких сборщиков, игровых библиотек, внешних картинок или звуков: все сцены и персонажи рисуются кодом. Русский интерфейс, плавно анимированная иллюстрация, адаптивная вёрстка и сохранение в `localStorage`.

## Запуск

Откройте `index.html` через локальный HTTP-сервер (ES-модули браузера не работают при открытии `file://`):

```sh
npm start
```

Затем откройте <http://localhost:3000>. Node.js-зависимости не требуются; `npm start` использует Python 3. Также подойдёт любой статический сервер, например `python3 -m http.server 3000`.

## Структура

- `index.html` — точка входа.
- `src/main.js` — запуск приложения.
- `src/data.js` — классы, главы, сцены, развилки, противники и товары.
- `src/game.js` — состояние прохождения, бои, экономика и сохранения.
- `src/render.js` — интерфейс, обработчики и кодовая отрисовка Canvas.
- `src/style.css` — адаптивная визуальная система.

## Прохождение и механики

Выберите один из трёх классов. Исследуйте коридор, кладовку и кухню, читайте записки и проверяйте тайники. Мурзилу, Пылесос-Пожирателя и Хозяина Макарон можно одолеть или разрешить часть конфликтов разговором. Решения влияют на доверие, стремление к свободе и знание правды; эти накопленные показатели определяют одну из трёх концовок, а не последний клик.

Формула атаки: `d6 + бонус класса`; шестёрка наносит критический урон `+3`. Сильная атака записывается в боевой журнал с броском и итоговым уроном. У врагов есть собственный бросок: базовый урон 3/4/5, а шестёрка усиливает удар. В бою доступны умение класса, защита, расходники и союзник-голубь. У Пылесоса слабый удар героя (1–2) усиливает втягивание; Мурзила пропускает каждый третий удар; Хозяин Макарон один раз предлагает порцию (+5 HP и два пропуска его атак).

Семена выдаются за победы, разрешение конфликтов без драки и тайники. У торговцев можно купить лечение, классовые улучшения, удвоение первого удара, подсказку о броске, голубя и «Эхо Первой Семечки». Улучшения дают +3 к максимальному здоровью и дополнительные применения умения, а также открывают эффект своей классовой ветки.

Сохранение происходит автоматически после игровых действий в `localStorage`. На стартовом экране доступно продолжение сохранённого прохождения. В интерфейсе всегда доступны здоровье и семена, а также отдельные экраны персонажа, сумки, журнала и бестиария.
